Definitions follow the paper; the full mathematical statements and proofs are in its appendix.

## Properties

The paper considers 20 properties; codes are the names used in the Python API and the command
line. Local Positivity is a single property, (LP), but Table 5 reports it in two rows: for
n = 2 sources, (LP<sub>0</sub>), and for n ≥ 3 sources, (LP<sub>1</sub>). The solver keeps these
two parts as separate variables, since some results only involve one of them (Theo. 1 and
Theo. 10 use (LP<sub>1</sub>)), and the codes `LP0` and `LP1` can be used in queries.

## Cases

Every analysis is run in one of two cases:

- **`bivariate`**: properties are required for n = 2 sources only, so (LP) is
  (LP<sub>0</sub>), and (LP<sub>1</sub>) is not used. Results proven only for n = 2 sources
  apply (Theo. 5).
- **`multivariate`**: properties are required for any number of sources, so (LP) is
  (LP<sub>0</sub>) and (LP<sub>1</sub>) together. Results that need at least three sources
  apply (Theo. 1 and Theo. 10). Measures defined only for n = 2 sources are skipped.

All the other results hold in both cases.
